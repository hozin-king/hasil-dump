DEFAULT [2131296421] The AI assistant sends what you write to the AI provider you set up, together with what it needs to answer: names, code, pseudocode and data from the open project, and files you let it read. With web access on, it also sends search queries to DuckDuckGo and opens web pages (or uses the provider's own web search). For OpenCode Go, the app also sends a random session ID that stays the same for each chat.

The provider handles this data under its own terms and privacy policy, with your API key. The developer of imodisa receives none of it, except an answer you report.

AI answers can be wrong or offensive. Check them before you rely on them, and use Report under an answer to flag it.
